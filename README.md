# Campo y Corriente

Guía de estudio de electromagnetismo (electrostática y circuitos DC), publicada con GitHub Pages.

## Páginas

- **Inicio** (`index.html`): resumen, unidades y un mini simulador de dipolo.
- **Teoría** (`teoria.html`): las seis unidades con fórmula clave, explicación, figuras y notas.
- **Demostraciones** (`demostraciones.html`): seis derivaciones paso a paso.
- **Simuladores** (`simuladores.html`): campo de cargas, superficie gaussiana, condensador y circuito RC.
- **Problemas** (`problemas.html`): 18 problemas con resultado y solución, más un quiz de 12 preguntas.
- **Formulario** (`formulario.html`): 51 fórmulas con buscador y filtro por unidad.
- **Laboratorios** (`laboratorios.html`): tres prácticas con lista de pasos y una curva V–I interactiva.

Es un sitio estático: HTML, CSS y JavaScript sin compilación. Las fórmulas se dibujan con KaTeX.
Estilos y código comunes en `assets/`; figuras en `fig/`.
